# 内容维护

网站的文字内容都放在这个目录中，保存后重新构建或部署即可生效。

- `about.md`：关于我页面的姓名、角色、邮箱、关注方向和正文。
- `notes/*.mdx`：学习书架中的文章。
- `hikes/*.md`：旅行日志中的地点级记录；只填写地点级经纬度，不填写 GPS 轨迹。
- `photos/*.md`：摄影作品的标题、题材、地点、图片和文字说明。

每个文件由两部分组成：顶部 `---` 之间是页面信息（front matter），下方是正文。数组字段使用 JSON 风格，例如 `tags: ["AI", "学习方法"]`。

新增一篇内容时，复制同类文件并改名。文件名会自动成为网址的一部分，例如 `notes/my-note.mdx` 对应 `/learning/my-note`。
